理論値と計算式

運動方程式

$ma = T - mg$
（鉛直上向きを正とする）

計算結果・各物理量の一覧

解説

  • 張力 $T$ と重力 $mg$ の関係： $T > mg$ のとき、物体は上向きに加速度 $a = \frac{T - mg}{m}$ で等加速度運動をします。
  • 力のつり合い： $T = mg$ のとき、合力は $0$ となり、物体は静止し続けるか、または等速直線運動（加速度 $0$）を行います。
  • 重力の方が大きい場合： $T < mg$ のとき、合力は下向きに働きます。物体が既に上昇中の場合は減速し、その後落下します（下端で停止します）。
