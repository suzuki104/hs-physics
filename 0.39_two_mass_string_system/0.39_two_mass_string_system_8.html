解説

  • 全体を1つの系と見なす場合： 外力 $F$ と全体の質量 $(m_A+m_B)$ によって加速度が決まります ($a = \frac{F}{m_A+m_B}$)。
  • 糸の張力 $T$ の役割： 物体Bを引っ張る唯一の力は「糸の張力 $T$」です。加速度 $a$ は、質量 $m_B$ を張力 $T$ で引くときの加速度です。
